## Завдання 5.4: Обчислення сум за допомогою рекурсії (Варіант 16)
- **Формула:** $\sum_{j=2}^{N} \frac{j(N - j)}{j^2 + (N - j)^2}$
- Реалізовано 5 взаємозамінних функцій:
  - `S0` — ітераційний спосіб (цикл `for`);
  - `S1` — обчислення на рекурсивному підйомі, параметр зростає ($j \to j+1$);
  - `S2` — обчислення на рекурсивному підйомі, параметр спадає ($j \to j-1$);
  - `S3` — обчислення на рекурсивному спуску, параметр зростає ($j \to j+1$);
  - `S4` — обчислення на рекурсивному спуску, параметр спадає ($j \to j-1$).
- Автоматизоване тестування `UnitTest_05_4.cpp` підтверджує 100% збіг значень усіх 5 функцій.
